# 掘金推广文

标题：我用 DeepSeek API 做了个 AI 合同审查工具，帮你避开合同里的坑（附完整实现）

## 背景

作为一个经常接外包的开发者，我踩过不少合同的坑。

最惨的一次：对方合同里写了"具体需求以甲方口头说明为准，甲方有权随时变更需求，乙方不得要求增加费用"。我没仔细看就签了，结果需求变了 5 次，白干了一个月，还不好意思说不。

从那以后我就想：能不能用 AI 帮我自动审查合同，把这些坑都标出来？

说干就干，用了一个周末，基于 DeepSeek API 做了个 AI 合同审查工具。

## 效果展示

输入一份合同，输出：

1. **合同类型判断**（服务合同/劳动合同/买卖合同/保密协议等）
2. **整体风险等级**（高/中/低）
3. **风险项列表**，每条包含：
   - 条款类型
   - 风险等级（高/中/低）
   - 原文摘录
   - 大白话解释（让非法律专业的人也能看懂）
   - 风险说明（这条有什么问题，可能导致什么后果）
   - 修改建议（具体怎么改，甚至给出可直接替换的条款文本）
4. **关键建议**（AI 给出的核心注意事项）

我故意写了一份埋了 10 几个坑的示例合同（在 examples/ 目录），测试效果还不错——大部分坑都识别出来了，包括：
- "需求以甲方口头说明为准"（高风险）
- "验收标准由甲方单方决定"（高风险）
- "乙方逾期违约金每日 5%"（高风险，年化 1825%，远超法定上限）
- "甲方逾期付款按活期利率支付违约金"（中风险，不对等）
- "保密期限永久"（中风险，不合理）
- "知识产权全部归甲方，包括乙方已有技术"（高风险）

## 技术实现

### 整体架构

```
用户输入（文本/文件）
    ↓
FastAPI 后端
    ↓
合同文本预处理（长度检查、编码处理）
    ↓
构建审查 Prompt（系统提示词 + 用户合同 + 输出格式要求）
    ↓
调用 DeepSeek Chat API（response_format: json_object）
    ↓
解析返回的 JSON
    ↓
风险分级统计 + 排序
    ↓
返回前端展示
```

### 核心：Prompt 设计

这是整个工具最关键的部分。好的 Prompt 决定了审查质量。

我的系统提示词包含几个部分：

1. **角色设定**：15 年执业经验的资深合同审查律师，精通民法典合同编
2. **审查重点**：列出 13 类高风险条款类型（违约责任、争议解决、知识产权、保密、付款、期限终止、不可抗力、保证担保、竞业限制、数据保护、免责条款、主体签署）
3. **风险等级标准**：高/中/低的判定标准
4. **输出要求**：严格 JSON 格式，字段说明，至少 5 条最多 15 条风险

用户提示词则包含：
- 合同文本
- 明确的 JSON schema 要求
- 几个关键约束（原文必须真实存在、不要编造、优先识别高风险）

### 为什么选 DeepSeek

1. **便宜**：deepseek-chat 模型 1 元/百万 tokens，一份 5000 字的合同审查成本不到 1 分钱
2. **中文好**：对中文法律文本的理解能力不错
3. **支持 JSON 模式**：`response_format: {"type": "json_object"}` 保证输出是合法 JSON
4. **新用户有免费额度**：适合个人项目

### 前端

纯原生 HTML + CSS + JS，没有用任何框架。原因：
1. 项目小，不需要框架
2. 原生加载快，没有依赖
3. 方便部署，一个 FastAPI 服务全搞定

前端做了这些交互：
- Tab 切换（粘贴文本/上传文件）
- 拖拽上传
- 加载动画
- 风险卡片（按高/中/低排序，不同颜色标识）
- 响应式布局（手机也能用）

## 快速开始

```bash
# 1. 克隆项目
git clone https://github.com/hq20211124/contract-review-ai.git
cd contract-review-ai

# 2. 安装依赖
pip install -r requirements.txt

# 3. 配置 API Key
cp .env.example .env
# 编辑 .env，填入你的 DeepSeek API Key

# 4. 启动
```

## 一些思考

### 这个工具的定位

这不是一个要取代律师的工具。它的定位是：
- **个人/小团队的合同初审工具**：签合同前先过一遍，把明显的坑标出来
- **法律意识普及工具**：大白话解释让非法律专业的人也能看懂合同
- **效率工具**：帮律师/法务做初筛，节省时间

重要合同还是建议找专业律师。

### 可以改进的地方

1. **支持 PDF/Word 上传**：目前只支持纯文本，后续可以加 python-docx 和 PyPDF2
2. **合同模板库**：提供各类标准合同模板，用户可以基于模板修改
3. **对比功能**：对比两份合同的差异
4. **历史记录**：保存审查历史（本地存储，不上云）
5. **多模型支持**：除了 DeepSeek，也支持 GPT、Claude、通义千问等

这个项目是开源的，但我也提供定制开发服务：
