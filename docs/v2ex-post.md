# V2EX 推广帖

标题：做了个 AI 合同审查工具，开源了，帮你识别合同里的坑

正文：

最近接外包的时候踩了个合同的坑——对方合同里埋了个"需求随时变更不另收费"的条款，没注意就签了，结果白干了一个月。

痛定思痛，用 DeepSeek API 做了个 AI 合同审查工具，帮你自动识别合同里的风险条款。

功能：
- 自动识别违约责任、争议解决、知识产权、保密条款、付款条款等 13 类高风险条款
- 高/中/低三级风险标注
- 每条风险给大白话解释 + 风险说明 + 具体修改建议
- 支持粘贴文本和上传 .txt 文件
- 本地部署，数据不上传第三方（除了 DeepSeek API）

实际效果：拿一份典型的甲方强势外包合同测试，识别出 17 个风险点，比如：

- 🔴 "如甲方认为项目未达到验收标准，有权拒绝支付任何费用，且乙方不得提出异议" → 甲方可以故意不验收赖账，建议改成"10个工作日内未提出书面异议视为验收合格"
- 🔴 "乙方逾期交付的，每逾期一日支付项目总费用5%的违约金" → 年化1825%，远超法律上限，建议改成每日0.5‰且不超过总额20%
- 🔴 "乙方使用的任何已有技术、代码、框架，均视为无偿授权甲方永久使用" → 你积累的代码库和开源框架全白送，建议区分定制代码和通用技术
- 🟡 乙方逾期每日5% vs 甲方逾期付款按活期利率0.2% → 违约金相差9000倍，严重不对等

技术栈：FastAPI + DeepSeek Chat + 原生前端，无框架依赖，Windows 双击 run.bat 就能跑。

GitHub：https://github.com/hq20211124/contract-review-ai

放了个示例合同在 examples/ 目录里，故意埋了 10 几个坑，可以直接拿来测试。

几点说明：
1. 这是个个人项目，审查结果仅供参考，重要合同还是找律师
2. 用的是 DeepSeek 的 deepseek-chat 模型，需要自己配 API Key（新用户有免费额度）
